## 🐇 Burrow — a Markdown workspace reader for Chrome

Notes, docs and ADRs live as a *folder* of Markdown files, but Markdown viewers show one file at a time. **Open one local `.md` file in Chrome and Burrow gives you the whole folder**: file tree, outline, and full-text search that jumps to the matching line. No setup, no network access, nothing leaves your machine.
