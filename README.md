#### 🐇 Burrow

I read a lot of Markdown, and Chrome shows it one raw file at a time. So I built [Burrow](https://github.com/CalvinKirs/burrow): open one local `.md` file and you get the whole folder, with a file tree, outline and full-text search. Everything stays on your machine.
